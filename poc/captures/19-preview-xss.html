How these properties are produced

Process

  1. Runs as an opt-in stage after the normal scan — LLM analysis, CVSS scoring, dataflow verification and oversight are unchanged.
  2. Fires only after oversight finalizes each finding's rule_id + cwe and dataflow sets its verification state, so every input is final.
  3. Computes a severity rank (0–100) deterministically from the CVSS vector, dataflow reachability (confirmed / unverified) and confidence — no LLM, no network.
  4. Decides novelty by coverage: a finding is novel only if no existing engine — SAST, DAST or SCA — can traditionally detect its rule. Anything an engine covers is tagged with the covering engine(s) in detectableBy (a list — some rules, e.g. SSRF, are found by both SAST and DAST) and marked not novel; the rest is classed by CWE. (Every finding here was detected by the LLM — detectableBy is a capability label on the rule, and doubles as a correlation datapoint against a real SAST/DAST/SCA result set.)
  5. Writes the fields back onto each result: rank at the top level, the rest into properties. Lookups stay out of the core rules file, so the scan's embedding step is untouched. Additive only — nothing is removed, reordered, or filtered.
  6. Cross-references SCA findings (e.g. Vulnerable Software Version) against the CISA KEV catalog — fetched once, held in memory — and sets exploitable + cisa_kev when the CVE is known-exploited in the wild. (A confirmed PoC-kit run is the other exploitability source. Reachability/rank is prioritization; this is evidence of real exploitation.)
  7. The UI (this mock) sorts on rank and filters on novelty and exploitability (exploitable → then narrow to KEV).

State column (dataflow verification)

TP dataflow agent confirmed the path — verified reachable (→ reachability 1.00)
NEW not dataflow-verified, or needs no dataflow to stand — the default (→ 0.75 / 0.45)
UNK dataflow tried but could not confirm — unverified, confidence lowered (→ 0.20)

Rank formula (severity, 0–100 · deterministic)

rank = 100 × ( 0.50·S + 0.35·R + 0.15·C ) → clamped 0–100
S Severity = 0.7·(CVSS base/10) + 0.3·E — E = mean of the exploitability sub-vector (AV, AC, PR, UI), de-ties equal CVSS scores
R Reachability — from dataflow: 1.00 confirmed (TP) · 0.75 no dataflow needed · 0.45 unverified (NEW) · 0.20 unconfirmed (UNK)
C Confidence = high 1.0 · medium 0.6 · low 0.3
